# Cursorama 原创配乐

这六首器乐由 Cursorama 项目的乐谱和音频合成代码制作，没有使用第三方音源、商业音乐、录音采样或生成式音乐服务。

可在 Cursorama 中离线试听、添加到工程，并用于个人或商业演示视频。音乐与生成代码采用仓库根目录的 MIT 许可证，不要求在导出视频中署名。

| 曲目 | 节奏 | 配器 |
| --- | --- | --- |
| 晨光键语 | 88 BPM | 温暖钢琴、柔和氛围、轻刷鼓组 |
| 静谧流光 | 72 BPM | 柔和电钢琴、宽阔氛围，无鼓组 |
| 轻快步调 | 104 BPM | 电钢琴、低音、松弛鼓组 |
| 霓光脉冲 | 116 BPM | 拨弦合成音、低音、电子鼓组 |
| 云端漫游 | 96 BPM | 木琴、柔和氛围、轻刷鼓组 |
| 夜色墨线 | 82 BPM | 低速钢琴、电钢琴和声、低音 |

每首含有独立旋律、和声进行、段落变化、演奏力度与微小时间变化、立体声空间，以及淡入淡出；不是单音或同一小段的循环拼接。

在项目根目录安装依赖后运行 `node scripts/generate-soundtracks.mjs` 可以重建全部音频。脚本使用 Node.js、项目已有的 esbuild 与 ffmpeg-static，不依赖 Python、网络服务或本机另装 FFmpeg。乐谱位于 `scripts/soundtracks/score.ts`，合成器位于 `scripts/soundtracks/synthesizer.ts`。

打包文件为 44.1 kHz 立体声 MP3，160 kbps。素材统一以约 −18 LUFS 母带响度处理，并在工作台默认以 30% 音量添加，用于轻声衬托讲解；可在音乐设置调整。

音乐片段自动在前 0.25 秒淡入、最后 0.6 秒淡出，短片段按时长缩短过渡。裁剪素材之后仍会平滑结束，预览与导出使用同一音量时间函数；当前没有手动编辑音量曲线的界面。

运行 `node scripts/check-soundtracks.mjs` 可检查实际 MP3 解码、响度、峰值、立体声差异和淡入淡出，并在 `.qa/soundtrack-audio-stats.json` 输出统计。
