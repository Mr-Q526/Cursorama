# Cursorama v0.3.0

这次更新扩充了原创配乐，并把音乐浏览和时间轴音频编辑做得更直观。

- **10 首原创配乐**：新增民谣、爵士、电影氛围和复古电子四种风格，曲库共 10 首、7 类风格。所有音频都由仓库内代码生成，可离线试听和使用。
- **更清楚的配乐列表**：改为紧凑曲目行，支持搜索、风格筛选、单曲试听、添加和查看工程中已使用的音乐。
- **真实音频波形**：时间轴音乐片段显示真实素材波形和实际音量曲线，裁剪、调节音量及自动淡入淡出会同步反映。
- **长音频保护**：长音频超出波形生成预算时仍可播放、编辑和导出，只降级为音量曲线显示，避免占用过多内存。
- **缩略图隔离**：切换工程、视频素材或片段区间时清理旧缩略图，避免显示上一段视频的画面。
- **界面与文档**：配乐面板在深色、浅色和小窗口下保持紧凑，README、使用指南和桌面版说明同步更新。

下载 `Cursorama-Setup-0.3.0-x64.exe` 安装。升级会保留本地工程、成片和存储位置设置。

验证覆盖 196 项单元测试、构建、完整桌面 smoke、10 首音频真实解码、配乐试听与保存恢复、时间轴波形、音量曲线和 MP4 音频导出。
