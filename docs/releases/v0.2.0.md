# Cursorama v0.2.0

这版加入基础视频剪辑、更多背景和项目封面，录制完成后可以直接整理讲解节奏并导出。

- **基础剪辑**：在播放头分割，调整片段入点与出点，删除片段，设置 0.25×～4× 倍速和原声音量。鼠标轨迹和镜头随源画面同步。
- **素材、音乐与字幕**：在当前播放位置插入本地视频、音乐或字幕；可编辑时间、音量和字幕文字，字幕直接显示在成片里。
- **媒体随工程保存**：原始录制、插入视频、音乐和字幕一起保存，重开工程无需查找原始素材。兼容旧工程。
- **更多背景**：新增 8 张原创矢量壁纸，总计 12 张；弹窗支持 Windows 灵感、macOS 灵感、极简光影分类和大图预览。
- **项目库封面**：工程和成片以封面卡片展示；旧视频在本机生成并缓存缩略图。
- **布局调整**：顶部移除录制和导出操作，「新建录制」位于左侧，「导出视频」位于工程工具栏；左下角设置和帮助并排。

下载 `Cursorama-Setup-0.2.0-x64.exe` 安装，也可以在旧版「设置 → 软件更新」中检查并下载。升级会保留工程、成片和保存位置。

`latest.yml` 与 `.blockmap` 用于内置更新；`SHA256SUMS.txt` 提供校验值。FFmpeg 源码及第三方许可随发布提供。
