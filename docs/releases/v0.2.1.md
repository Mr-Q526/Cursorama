# Cursorama v0.2.1

这次加入逐帧定位、自定义背景、离线原创配乐与聚焦音效，同时改进自动聚焦和工作室布局，让制作和观看演示更顺畅。

- **逐帧定位**：左右方向键暂停播放并前进／后退一帧，新录制保留采集帧率，时间显示「分:秒:帧」；进度条获得焦点时也可逐帧移动。
- **更多壁纸与自定义图片**：背景库扩充到 24 张原创壁纸，支持上传图片，随工程保存、恢复并用于导出。
- **离线原创配乐**：左侧新增「音频与配乐」，提供 6 首代码合成的原创器乐，支持按风格浏览、试听和插入，也可导入本地音频。
- **独立聚焦音效**：4 款原创短音效，可试听、开关和单独调节音量；镜头进入聚焦时响一次，持续输入不重复响，与原声和持续播放的配乐叠加。

- **操作节奏聚焦**：点击后短暂放大并缓慢回到全景；连续点击合并并平滑切换位置，移开的鼠标不会带走镜头。
- **持续输入聚焦**：追踪 Windows 输入控件或文字光标，输入、滚动和拖动延长镜头。文字光标小范围移动时保持稳定，宽输入框适当降低倍率，输入时减轻倾斜。只保存活动时间和位置，不保存按键或文字。
- **简洁工作室**：收紧导航与工程工具栏，参数移到左侧，右侧放大预览，底部时间轴铺满；默认只显示视频和镜头轨道，音乐、字幕和鼠标轨迹按需显示。背景直接提供 12 张缩略图。

- **分类设置**：外观、本地存储、关于分别展示，弹窗尺寸保持稳定，底部操作固定可见。
- **新的关于页**：集中展示应用信息、版本检查和更新日志，提供作者、开源仓库和意见反馈入口。
- **请作者喝杯咖啡**：关于页可展开微信和支付宝赞赏二维码，README 同步提供介绍与原图。
- **更清楚的更新状态**：集中显示当前版本、新版本和下载进度；下载中移除无效按钮，下载完成后显示安装操作，失败时提供重试。
- **可读的版本说明**：修复 GitHub 更新说明直接显示 HTML 标签的问题，支持标题、列表、强调和代码名称。说明默认收起，不加载远程截图或执行外部脚本。
- **更顺手的交互**：更新提醒直接进入关于页；切换分类保留存储目录草稿，并提示未保存的修改；支持键盘切换。
- **黑白主题**：统一间距、文字层级、边框和按钮，适配较小桌面窗口。
- **更轻的窗口标识**：移除左上角 Logo 的白色底块，图标使用透明背景并适配黑白主题。
- **更可靠的短录制**：等待录制编码器就绪再开始计时，拒绝创建没有画面的空工程。

下载 `Cursorama-Setup-0.2.1-x64.exe` 安装，也可以在旧版设置的更新入口下载并安装。新版入口为「设置 → 关于」，升级保留工程、成片与存储配置。
