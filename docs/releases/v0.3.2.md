# Cursorama v0.3.2

这次修复了确认录制来源后，系统鼠标移动变得卡顿的问题。

- **修复鼠标卡顿**：全局键鼠钩子改由独立消息线程处理，录制准备、倒计时和录制期间，采样休眠不再延迟系统输入。
- **改善繁忙时的响应**：鼠标轨迹输出与全局输入处理分离，输出暂时阻塞时，系统鼠标仍能及时响应。
- **补充性能回归验证**：覆盖追踪开启、输出阻塞和停止清理，防止类似卡顿再次出现。

本机对比测试中，追踪开启后的输入延迟中位数由约 15.7 毫秒降至约 0.3 毫秒。

下载 `Cursorama-Setup-0.3.2-x64.exe` 安装，也可以在「设置 → 关于」检查更新。升级会保留本地工程、成片和存储位置设置。

验证：单元测试、构建、原生输入延迟测试与录制流程专项通过。完整桌面冒烟测试在聚焦音效导出检查处失败，该检查发生在原生鼠标追踪验证之前。
