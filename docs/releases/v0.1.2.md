# Cursorama v0.1.2 · 悬浮录制与提词器

录制开始后，主窗口自动隐藏，通过悬浮小组件查看时长、暂停／继续和结束录制；加入提词器，并修复圆角边缘和全屏播放操作。

## 本次变化

- 删除「在预览中点击设置焦点」及点击设焦点操作，自动焦点依据录制时的鼠标点击位置。
- 修复圆角外漏出白色矩形的问题，预览和导出使用相同的圆角渲染。
- 全屏预览增加底部悬浮控制栏，支持进度拖动、从头播放、播放／暂停、声音和退出全屏；移动鼠标显示，播放时自动淡出。
- 桌面录制开始后隐藏主窗口，显示可拖动、保持置顶的录制小组件；结束后自动回到编辑器。
- 暂停时间不计入成片，声音、鼠标时间轴和计时同步暂停；忽略悬浮控件区域内的鼠标操作。
- 补充录制视频的有效时长元数据，按输出帧率补足静止画面的片尾，保证进度与视频时长一致。
- 在「新建录制 → 提词器」中设置讲解稿，支持自动滚动、调速、字号、镜像和回到开头；录制暂停或收起窗口时同步停止滚动。
- Windows 悬浮控件和提词器设置了屏幕采集排除。

## 操作入口

- 录制前展开「提词器」，输入讲解稿并开启「录制时打开提词器」；录制中也可通过小组件打开。
- `Ctrl + Shift + F8` 暂停／继续录制，`Ctrl + Shift + F9` 结束录制。
- 双击预览画面进入或退出全屏，也可使用全屏按钮；Esc 退出。
