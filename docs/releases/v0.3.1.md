# Cursorama v0.3.1

这次理顺了打开软件、录制和查看工程的流程，精简侧栏，让项目库成为统一入口。

- **精简导航**：删除侧栏的「录屏工作室」「音频与配乐」及「打开项目／导入素材」入口。配乐与聚焦音效集中在工程编辑器的「配乐」标签。
- **统一项目入口**：启动默认进入本地项目库，在列表中打开工程继续编辑；导入工程和视频统一放在项目库顶部。
- **连贯的录制流程**：新建录制先打开准备弹窗，确认录制来源后倒计时开始；取消准备保留当前页面。录制结束自动保存工程并进入编辑器。
- **独立成片预览**：点击成片进入播放页面，可返回项目库、编辑关联工程或打开文件位置。
- **保留浏览上下文**：返回项目库时保留搜索和筛选；离开修改过的工程前自动保存。
- **更可靠的页面切换**：修复历史导航与页面状态同步，并在退出预览时释放视频资源；没有打开工程时自动回到项目库。

下载 `Cursorama-Setup-0.3.1-x64.exe` 安装，也可以在「设置 → 关于」检查更新。升级会保留本地工程、成片和存储位置设置。

验证覆盖 196 项单元测试、构建、完整桌面 smoke 和录制控制专项验证。
