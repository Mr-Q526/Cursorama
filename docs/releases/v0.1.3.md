# Cursorama v0.1.3 · 紧凑顶部栏与毛玻璃边缘

桌面窗口顶部栏重新布局，录制画面增加可调节的毛玻璃边缘，并彻底清理预览点击设焦点的旧逻辑。

## 本次变化

- 顶部栏贯通窗口，统一品牌、页面路径、录制／导出操作与窗口按钮的尺寸和间距，适配黑白两种主题。
- 保留顶部拖动、双击最大化／还原、最小化和关闭；设置弹窗打开时窗口按钮仍可操作。
- 「背景」面板新增「毛玻璃边缘」，默认强度 55%，设为 0 可关闭。边缘柔化并融合背景，中心文字保持清晰。
- 毛玻璃随圆角和三维运镜同步变化，预览和导出共用渲染器，支持高分辨率输出和无 WebGL 时的平面渲染。
- 工程保存毛玻璃强度，旧工程自动补上默认值。
- 删除点击预览设焦点的坐标映射与十字光标残留；点击预览不会创建或改变镜头，添加镜头沿用录制中的最近一次鼠标点击。

## 下载与升级

下载 `Cursorama-Setup-0.1.3-x64.exe` 安装。已安装 0.1.1 或更新版本的用户可在「设置 → 软件更新」检查、下载，再点击「重启并安装」。升级保留工程、成片和保存位置设置。

附件包括 Windows x64 Setup 安装包、更新差分信息、`latest.yml`、SHA-256 校验文件与随程序使用的 FFmpeg 对应源码归档。

验证覆盖 69 项单元测试、构建、桌面录制、暂停／继续、全屏播放、工程恢复、圆角与毛玻璃边缘、4K 导出、窗口按钮及更新检查，以及独立目录中的安装、覆盖升级和卸载保留文件。

查看 [使用指南](https://github.com/Mr-Q526/Cursorama/blob/v0.1.3/docs/使用指南.md)，或通过 [Issues](https://github.com/Mr-Q526/Cursorama/issues) 反馈问题。
