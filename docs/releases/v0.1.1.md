# Cursorama v0.1.1 · 桌面界面、安装与更新

本版使用自己的顶部栏，提供 Windows Setup 安装包，并加入自动检查、手动检查、下载和安装更新的能力。

## 桌面界面

- 隐藏 Windows 原生标题栏，窗口控制融入软件现有顶部栏，适配黑白两种主题。
- 顶部空白区域可以拖动窗口，双击可最大化或还原；右上角提供最小化、最大化／还原和关闭按钮。
- 设置弹窗打开时，窗口控制仍可使用；录制期间的关闭保护继续生效。

## 下载与安装

下载 `Cursorama-Setup-0.1.1-x64.exe`，运行并选择安装目录，安装完成后通过桌面或开始菜单快捷方式启动。安装包内已包含桌面运行环境和视频编码器。

旧版 `0.1.0` 未包含自动更新，需要先手动安装本版；之后可以直接在软件内获取新版本。已有工程和成片可通过原目录继续打开；设置中可以指定原来的保存与导出位置。

## 软件更新

- 默认启动后自动检查 GitHub Release，使用期间每 4 小时检查一次。
- 设置弹窗增加「软件更新」，显示当前版本，支持手动检查和关闭自动检查。
- 发现新版后查看版本说明、下载更新，下载过程中显示进度。
- 下载完成并通过文件摘要校验后，点击「重启并安装」。程序先保存当前工程，再关闭并安装，随后重新启动。
- 网络错误、下载中断或校验失败支持重试；不自动下载，不在普通退出时安装。
- 录制、导出和保存操作进行时，不执行更新安装。
- 安装器可选择目录；覆盖升级和卸载保留工程、成片、存储设置及用户另行放入的文件。
