# Cursorama v0.3.3 · macOS 鼠标效果与全屏窗口录制

本次提供 Apple Silicon（arm64）Mac 安装包，修复鼠标效果缺失、全屏及隐藏窗口预览异常。

- **鼠标追踪**：记录移动、点击、拖动和滚动，支持基于轨迹的自动运镜与点击效果；暂停、取消和结束录制时释放追踪资源。
- **跨桌面窗口**：补充枚举其他桌面空间中的全屏、隐藏与最小化窗口。
- **来源预览**：补充原生缩略图；截图接口无法处理全屏窗口时，短暂采集首帧并立即停止。无预览时显示应用图标，不再出现破图文字。
- **Mac 打包**：附带原生采集助手、FFmpeg 与依赖许可证、对应构建源码；保留 v0.3.2 的 Windows 鼠标卡顿修复。

下载 `Cursorama-0.3.3-mac-arm64.dmg`，打开后拖入 Applications。需要 macOS 12.3 或更新版本；原生来源缩略图采集需要 macOS 14 或更新版本，旧系统可使用应用图标回退。

首次录制需在“系统设置 → 隐私与安全性”中允许屏幕录制与输入监控，并按提示重启应用；开发模式下权限对应 Electron。Mac 版暂不支持 Windows 版的输入焦点识别和自动更新。

使用临时签名，未做 Apple Developer ID 签名或公证；如被系统阻止，请在“系统设置 → 隐私与安全性”中允许打开。

验证：单元测试、TypeScript 检查、构建、Mac 实机录制与导出冒烟测试通过；覆盖全屏来源缩略图、选择界面、失败回退和鼠标移动／点击。录制验证仅使用 Cursorama 自身窗口。麦克风和系统音频采集未验证。

本 Release 仅提供 Mac 安装包。Windows 默认下载与自动更新继续使用 v0.3.2。

`Cursorama-0.3.3-mac-source.tar.gz` 包含对应提交的项目源码及 FFmpeg、x264、libvpx、Opus 原始源码归档。文件校验值见 `SHA256SUMS-mac.txt`。
