# Cursorama v0.1.0 · 光标即导演

Cursorama 的首个公开版本。录下产品操作、教程和功能讲解，根据鼠标轨迹自动生成缩放、平移与三维透视，编辑后导出为演示视频。

## 下载与启动

下载 `Cursorama-0.1.0-windows-x64.zip`，完整解压到有写入权限的目录，然后运行 `Cursorama.exe`。桌面运行环境和视频编码器已包含在压缩包中。

程序依赖同目录的运行文件，请保留整个解压目录。工程默认保存到程序目录下的 `projects`，成片默认保存到 `exports`；点击左下角齿轮可以分别修改这两个位置。

## 本版功能

- 先选择屏幕或应用窗口，确认实时预览后录制；倒计时默认 3 秒，可选关闭、5 秒或 10 秒。
- 使用原始来源分辨率采集，可选麦克风和系统声音；保留系统真实鼠标，避免重复光标。
- 跟随鼠标移动和点击生成镜头，提供清晰聚焦、电影运镜、空间漫游和全景展示四种风格。
- 时间线编辑镜头时间、倍率和焦点，调整点击涟漪、留白、圆角与阴影。
- 黑白两种界面主题，以及四款原创系统壁纸风格的视频背景。
- 本地自动保存工程，独立项目库恢复编辑并查看历史成片。
- MP4 / WebM 导出，最高 4K，30 / 60 fps，支持横屏、竖屏、方形和区间裁剪。

录制中按 `Ctrl + Shift + F9` 结束，也可使用托盘菜单。左下角问号按钮可打开内置运镜演示。
