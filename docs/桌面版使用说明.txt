Cursorama v0.2.0 · 光标即导演

启动
运行 Setup 安装包，选择安装目录，安装完成后通过快捷方式启动。
桌面运行环境和视频编码器已包含在安装包中。

窗口控制
桌面版使用软件自己的顶部栏；拖动顶部空白区域可移动窗口，双击可最大化或还原。
右上角提供最小化、最大化／还原和关闭按钮；设置弹窗打开时也可使用。

录制演示
1. 点击左侧“新建录制”，选择屏幕或应用窗口。
2. 确认实时预览，设置麦克风、系统声音和倒计时，默认 3 秒。
3. 可展开“提词器”，粘贴讲解稿并开启“录制时打开提词器”。
4. 点击“开始录制”，倒计时结束后主窗口自动隐藏，悬浮小组件显示有效时长。
5. 小组件支持暂停／继续，快捷键 Ctrl + Shift + F8；暂停时间不会进入视频。
6. 点击小组件的结束按钮或按 Ctrl + Shift + F9，返回编辑器，也可通过托盘菜单结束。
7. 调整镜头、背景和画布，再点击“导出视频”。

提词器
在新建录制弹窗中设置讲解稿，稿件自动保存在本机。
录制时可从小组件打开或收起提词器，拖动标题区域调整位置，也可调整窗口大小。
支持自动滚动、速度、字号、镜像和回到开头；暂停录制或收起提词器时停止滚动。
悬浮控件和提词器设置了 Windows 屏幕采集排除。

编辑
点击时间线里的镜头，可调整时间、倍率、风格和启用状态。
点击视频片段可裁剪入点／出点、调整 0.25～4 倍速和原声音量。
时间轴剪刀按钮在播放头分割视频，选中后可删除片段、效果、音乐或字幕。
右侧“剪辑”可插入本地视频和音乐，添加字幕并设置时间；字幕会烧录到成片。
插入素材随工程一起保存，重新打开不依赖原文件的位置。
焦点根据录制时的鼠标点击位置生成，预览画面不会通过点击修改焦点。
空格播放或暂停，左右方向键跳转。
双击画面进入或退出全屏，全屏底部悬浮控制栏支持进度拖动、播放／暂停、声音和退出。
左下角问号按钮可查看内置运镜演示。
在“背景 → 毛玻璃边缘”中调整柔化强度，默认 55%，设为 0 可关闭；画面中心保持清晰，导出包含相同效果。
“背景 → 更多背景”提供 12 张原创壁纸，按 Windows 灵感、macOS 灵感和极简光影分类。

本地保存
工程默认位于程序目录下的 projects 文件夹。
成片默认位于程序目录下的 exports 文件夹。
录制结束和编辑后会自动保存，左侧“本地项目库”可继续打开工程或成片。
项目库以封面卡片展示工程和视频，便于区分。
左下角齿轮打开设置弹窗，可分别修改保存位置、导出位置，并切换黑白主题。
修改位置后，已有工程继续保存在原位置，历史内容仍可在项目库中打开。

软件更新
默认启动后自动检查 GitHub Release，使用期间每 4 小时检查一次。
在设置的“软件更新”中，可关闭自动检查，也可以手动点击“检查更新”。
发现新版本后，点击“下载更新”，下载和校验完成后点击“重启并安装”。
安装前会保存当前工程，录制和导出时不执行安装，升级保留工程、成片和存储设置。
旧版 0.1.0 需先手动安装本版，之后可使用软件内的更新功能。
